# QA Mode v1.5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace v1's static colored-tile QA panes with simultaneous live content (terminal text + sim screenshots), suppress non-pair UI chrome in QA, add accessibility labels on grid tiles, and a position-swap chip button.

**Architecture:** iOS extends single-window content state to per-windowId maps (Approach A). In QA mode, iOS requests `RequestContentMessage(windowId:)` for both pair halves on every refresh tick; each pane renders the existing `InlineTerminalContent` view keyed on its own windowId. Sim stays read-only (TextField + Send disabled when target selected). No Mac wire changes.

**Tech Stack:** SwiftUI, Apple Observation framework, `@AppStorage`, existing `InlineTerminalContent` View, existing `RequestContentMessage` / `TerminalContentMessage` wire format.

**Spec:** `docs/superpowers/specs/2026-05-07-qa-mode-v1.5-design.md`

```swift
/// Pure helpers for mutating the per-windowId content state maps that
/// QA mode (and the inline single-window flow) read through. Pulled out
/// of MainiOSView so unit tests don't have to instantiate the whole view.
enum ContentMapMutations {
    static func applyContent(
        windowId: String,
        text: String?,
        screenshot: String?,
        urls: [String],
        into textMap: inout [String: String],
        _ screenshotMap: inout [String: String],
        _ urlsMap: inout [String: [String]]
    ) {
        if let text { textMap[windowId] = text } else { textMap.removeValue(forKey: windowId) }
        if let screenshot { screenshotMap[windowId] = screenshot } else { screenshotMap.removeValue(forKey: windowId) }
        urlsMap[windowId] = urls
    }

    static func purgePairContent(
        pair: (String, String),
        from textMap: inout [String: String],
        _ screenshotMap: inout [String: String],
        _ urlsMap: inout [String: [String]]
    ) {
        for id in [pair.0, pair.1] {
            textMap.removeValue(forKey: id)
            screenshotMap.removeValue(forKey: id)
            urlsMap.removeValue(forKey: id)
        }
    }
}
```

```swift
    /// the selected window in normal mode, OR both pair halves in QA mode.
    /// Mac handles each request independently; payloads land in
```
