## Known caveats / gotchas to remember

- **iOS UNNotificationCategory registration is per-cold-launch.** If the user installs a new build but doesn't force-quit + relaunch, `setNotificationCategories(...)` doesn't run, so action buttons don't appear on alerts. Always tell the user to force-quit + relaunch after pushing a category change.
- **`NSWorkspace.shared.notificationCenter` is NOT `NotificationCenter.default`** — Workspace notifications post through their own bus. Wake observer (§22) and active-app observer subscribe to `NSWorkspace.shared.notificationCenter`.
- **`xcodebuild -scheme QuipMac` runs from `QuipMac/` cwd**; Release builds use `derivedDataPath build/` at repo root → `build/Build/Products/Release/Quip.app`. Mismatching cwds produces a confusing "directory does not contain an Xcode project" error.
- **Test fire windowId is synthetic** — taps deep-link to a window that isn't in the live list. Acceptable for diagnostic; tap falls through to default app open behavior.
- **Mac stable-signing recipe is non-negotiable.** Never `rm -rf /Applications/Quip.app` — TCC grants reset. Use the 4-step sequence in `reference_quip_install_recipe.md`.
- **Hook auto-recap fires once per session.** Sentinel at `~/.claude/.recap-fired-<session_id>` blocks re-firing. To force a re-trigger in the same session, delete the sentinel first.
