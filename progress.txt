- **Learnings for future iterations:**
  - Two cursor "zero" states are NOT equivalent: a missing cursor FILE (fresh
    root -> seed to EOF, skip history) vs a persisted {0,0} (resume from start).
    SwrmCursorStore.load() returns .zero for both; SwrmCursorStore.exists() is the
    discriminator. Don't collapse them or you reintroduce the first-launch storm.
  - The first-launch seed reuses readIncremental's torn-line discipline instead
    of stat()'ing file size — so a half-written trailing line at configure time
    isn't swallowed; it's held back and delivered whole on the next real pump.
  - macOS app teardown: NSApplication.willTerminateNotification is the reliable
    quit hook for a menubar app (there's no meaningful "background"); it fires on
    NotificationCenter.default. The closure is @Sendable under Swift 6 — use
    MainActor.assumeIsolated to touch the @MainActor store (we scheduled it on

## 2026-06-16 — US-005 (TranscriptCorrector for both PTT paths) [iOS PRD]
Thread: https://ampcode.com/threads/$AMP_CURRENT_THREAD_ID
- NEW QuipiOS/Services/TranscriptCorrector.swift: a Foundation-only `struct`
  value type (TranscriptCorrector.shared) holding a curated mishearing->canonical
  rule set. Each rule is a case-insensitive NSRegularExpression; init wraps every
  curated pattern in `\b(?:…)\b` so matching is WHOLE-WORD/PHRASE only and
  stringByReplacingMatches touches only the matched span -> surrounding text +
  leading/trailing whitespace (the send pipeline relies on it) are preserved.
  Rules ORDERED longest-phrase-first so the specific form wins:
  `x\s*code\s*gen`->Xcodegen, `tail\s+scale`->Tailscale, `mono\s*type`->monospace,
  `web\s*socket`->WebSocket, `co[-\s]+dex`->Codex, `x\s*code`->Xcode.
  Conservative: the ONLY real-English remap (monotype->monospace) is the user's
  documented dictation artifact; bare "codex" is deliberately NOT remapped (real
  word) — only the hyphen/space two-token forms via `co[-\s]+dex`. Replacement uses
  NSRegularExpression.escapedTemplate so a future $/\ in a canonical term stays literal.
- WIRED into SpeechService.stopRecording at BOTH final exits (final transcript
  ONLY, never partials):

    `let corrected = …correct(text); self.transcribedText = corrected; cb?(corrected)`.

    biasing — that only exists on the local SFSpeech request at :620/:774).
