## Key file facts — WindowListSidebar.swift

- `windowTier(_ window: ManagedWindow) -> Int`: tier 0 = `window.isTerminal` (iTerm2 + Terminal.app), tier 1 = `window.targetKind == "simulator"`, tier 2 = everything else. THIS is the target classifier — targets to toggle = `windowTier(w) <= 1`.
- `magicSort()` is the wand button action (header()). It sorts windowManager.windows and writes `windowOrder` inside `withAnimation(.easeOut(duration: 0.22))`. Extend THIS tap to also toggle enable-state; keep the sort logic byte-for-byte.
- Enable/disable path: `windowManager.toggleWindow(id, enabled: Bool)`. `WindowRow.enabledBinding` reads `window.isEnabled` live and writes through onToggle → toggleWindow, so a wand-driven enable shows up in the checkbox automatically. NEVER mirror enabled-state into a private @State.
- Toggle-all predicate: `let targets = windowManager.windows.filter { windowTier($0) <= 1 }`; `let allOn = !targets.isEmpty && targets.allSatisfy { $0.isEnabled }`; `let enableAll = !allOn`; for each target call `windowManager.toggleWindow($0.id, enabled: enableAll)`. Empty targets → skip toggle, still sort, no crash.
- DO NOT TOUCH: `dragReorder` (.onMove), `moveWindow` / `moveAction` (hover chevrons), `syncWindowOrder`, `orderedWindows`. Sort order, tiers, attention-first, drag, chevrons all stay as-is.
